# Your off route

Every detour counted. An interactive September recap set in Providence, Rhode Island.

## Preview

Current hosted version: https://off-route-september-story.scarletthzy.chatgpt.site/

Serve this folder with any static web server, for example `python3 -m http.server 8000`, then open http://localhost:8000. No build or package installation is required.

## Features

- Manual swipe-up navigation, with one chapter per gesture; no autoplay.
- Animated numbers and reduced-motion support.
- iPhone 17-proportioned preview, centered layouts, and a single next arrow.
- Locally bundled Noto Sans and Source Serif 4 fonts.

## Files

`index.html` contains the nine story pages; `style.css` handles layout; `app.js` handles gestures and counters; `assets/` contains images and fonts.

Trip statistics are fictional; Providence-themed illustrations are AI-generated.
